# Contributing

Contributions should preserve the established chronology, English-only visible interface, and five-test message protocol.

Before opening a pull request:

1. Serve the repository over HTTP and follow the full route from `index.html` to `game.html`.
2. Confirm every local link resolves.
3. Confirm visible interface text is English.
4. Do not add personal names, private media, unlicensed assets, tracking scripts, or external audio/video.
5. Record any new runtime dependency and its license in `THIRD_PARTY_NOTICES.md`.
6. Preserve SCP attribution and CC BY-SA 3.0 licensing.
