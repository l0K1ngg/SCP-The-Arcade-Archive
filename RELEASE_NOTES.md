# SCP-8707: The Arcade Archive — v1.0.0

The first public release of **SCP-8707: The Arcade Archive** is now live.

Recover the surviving records of Incident 8707-C4, mount a magnetic medium sealed since 1991, and follow an impossible live handshake back to the cabinet in Site-192 deep storage. The sequence concludes with five interactive containment tests covering memory, barrier integrity, structural load, signal recovery, and target extraction.

## Highlights

- A connected archival narrative spanning 1991 and 2026
- Five distinct browser-based interactive tests
- Keyboard and arcade-style controls
- Canvas, WebGL, CSS animation, and procedural Web Audio
- Fully English interface
- No external audio, video, private photographs, tracking, or account requirements
- Static deployment with no build step or backend

## Play

<https://scp-the-arcade-archive.vercel.app/>

## Controls

- `W A S D` or arrow keys — move
- `Space`, `Enter`, or **ACT** — interact
- Drag the generated test token into the slot to initialize the live sequence
